# My macOS Profile

This private repository contains your personal Mac configuration. The public
framework lives at `@DOTFILES_REF@`; this repository contains only your choices.

## Where to make changes

- `apps/homebrew-casks.nix` — GUI applications installed with Homebrew.
- `apps/nix-packages.nix` — command-line tools installed with Nix.
- `apps/mac-app-store.nix` — Mac App Store applications and numeric IDs.
- `macos/default.nix` — your macOS preferences.
- `hosts/@HOSTNAME@.nix` — settings specific to this Mac and username.
- `home/default.nix` — Home Manager configuration and adopted-file mappings.
- `home/files/` — private files restored into your home directory.
- `identity.nix` — personal identity data used by modules you explicitly import.

`flake.nix` connects this profile to the public framework. `flake.lock` is
generated by Nix and records the exact framework version.

## Normal workflow

1. Edit one focused Nix file.
2. Review the change with `git diff`.
3. Check the profile:

   ```bash
   nix flake check
   ```

4. Rebuild this Mac:

   ```bash
   darwin-rebuild switch --flake .#@HOSTNAME@
   ```

The `dot rebuild` command is a convenience wrapper around the same flake.

## Update the public framework

Updating the framework changes only `flake.lock`; it does not rewrite your app
lists, preferences, hosts, or adopted files.

```bash
nix flake update dotfiles
git diff -- flake.lock
```

Evaluate or rebuild before committing the lock-file change.

## Back up and restore

Push this repository to a **private** Git remote. A repository that exists only
on the same Mac is not a backup.

On another Mac, clone the private repository, install the public framework, add a
file under `hosts/` for that Mac, and rebuild its hostname configuration.

## Generated files

- `flake.lock` is generated by Nix; do not edit it manually.
- The marked section in `home/default.nix` may be updated by `dot adopt`.
- Everything else is ordinary Nix that you may read and edit directly.
